# 3. ディーラー設定（会社管理者・支店管理者向け）

**会社管理者** と **支店管理者** が行う、担当者・支店の管理の方法を説明します。  
画面右上のメニュー（**`≡`**）→ **「ディーラー設定」** で開き、**「受注一覧に戻る」** で受注一覧に戻ります。  
閲覧者には「ディーラー設定」は表示されません。**会社管理者のみが操作できる項目には {*} を付けています。**

---

## 1. 役割ごとにできること

| 役割 | ディーラー設定でできること |
| :--- | :--- |
| **会社管理者** | 自社のすべての担当者の招待・編集・無効化・再有効化・招待の取り消し、役割・所属支店の変更、支店の追加・名称変更・無効化 |
| **支店管理者** | 自分の支店の閲覧者の招待・編集・無効化・再有効化・招待の取り消し、自分自身の氏名・担当施設の変更 |
| **閲覧者** | なし（受注一覧の閲覧のみ） |

- 注文を閲覧できる範囲は **会社単位** です。役割・支店・担当施設の設定によって、閲覧できる範囲は変わりません。
- 自分自身の役割の変更・無効化はできません。
- 所属支店が設定されていない支店管理者は、担当者を管理できません。会社管理者に所属支店の設定を依頼してください。

---

## 2. 担当者を招待する

1. **「担当者を招待」** を開きます。
2. **勤務先メールアドレス**、氏名（任意）、役割 {*}、所属支店 {*} を入力して **「招待」** を押します。
   - 支店管理者が招待する場合は、自分の支店の **閲覧者** として招待されます。
3. 招待された人がそのメールアドレスでログインし、確認コードで本人確認をすると参加します（「[ログインと本人確認](./01-login.md)」）。

- 参加前の担当者は **「参加待ち」**（期限切れは **「招待の期限切れ」**）と表示されます。**「招待を取り消す」** で取り消せます。
- 期限が切れた場合や取り消した場合は、もう一度招待してください。

---

## 3. 担当者を編集・無効化する

担当者の一覧で、各担当者の **「編集」** を押します。

- **氏名**・**担当施設** を変更できます。
- **役割** {*}・**所属支店** {*} を変更できます。
- **「無効にする」** で、その担当者は受注一覧を利用できなくなります。**「有効に戻す」** で再び利用できます（有効に戻した後は、ログイン時にもう一度確認コードでの本人確認が必要です）。
- 会社管理者の任命・解除、支店管理者の任命・解除は、会社管理者のみが行えます {*}。
- 一覧は **「支店で絞り込み」** で、支店ごとに表示できます。

### 担当施設

- 担当施設は、受注一覧の **「担当」の印** と **「担当施設のみ」** ボタン、初めて開いたときの医療機関の選択に使う、表示のための設定です。
- 候補は、貴社に閲覧を許可している医療機関だけです。担当施設を設定しても、閲覧できる範囲は変わりません。
- 受注一覧での医療機関のチェックは各担当者の端末に記憶されるもので、担当施設の登録は変わりません。

---

## 4. 支店を管理する {*}

- **支店名** を入力して **「追加」** で支店を追加します。
- **「名称変更」** で支店名を変更し、**「無効にする」**／**「有効に戻す」** で支店を無効・有効にします。
- 支店は担当者を整理するための表示用です。注文を閲覧できる範囲は変わりません。
- 担当者が所属している支店は無効にできません（先に担当者の所属支店を変更してください）。
- 他の支店への異動（所属支店の変更）は会社管理者が行います。

{*} 会社管理者のみ操作できます。
