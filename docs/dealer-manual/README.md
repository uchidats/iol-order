# ディーラー用マニュアル

ディーラー（販売店）の担当者向けの、受注一覧の操作マニュアルです。  
スマートフォン・パソコンのどちらからでもご利用いただけます。  
このマニュアルは、画面右上のメニュー（**`≡`**）→ **「使い方・ヘルプ」** からいつでも開けます（ログイン前でも閲覧できます）。

---

## マニュアル一覧

1. **[ログインと本人確認](./01-login.md)**
   - 招待を受けてからの参加の流れ
   - ログイン方法（Google・Microsoft・メールのリンク）
   - 確認コードによる本人確認・「この端末（ブラウザ）を記憶する」
   - 複数の会社に所属している場合・ログアウト

2. **[受注一覧](./02-orders.md)**
   - 表示される注文の範囲（自社宛ての明細だけ）
   - 医療機関の選択（自動で記憶）・「担当」と「担当施設のみ」
   - 注文日順・手術日順の表示（注文日の検索・もっと見る・過去の注文をもっと見る）
   - 出力（印刷・PDF・Excel）
   - 受注詳細・注文メールの状態

3. **[ディーラー設定（会社管理者・支店管理者）](./03-settings.md)**
   - 役割ごとにできること
   - 担当者の招待・編集・無効化、担当施設の設定
   - 支店の追加・名称変更・無効化
   - テーマカラー（画面上部の色・ボタンなどの色。会社で共通）

4. **[よくある質問](./04-faq.md)**

## 役割について

担当者には、次のいずれかの役割があります。役割は会社管理者（支店の閲覧者は支店管理者も）が設定します。

| 役割 | できること |
| :--- | :--- |
| **閲覧者** | 受注一覧の閲覧 |
| **支店管理者** | 受注一覧の閲覧、自分の支店の閲覧者の管理（ディーラー設定） |
| **会社管理者** | 受注一覧の閲覧、自社のすべての担当者・支店の管理、テーマカラーの設定（ディーラー設定） |

- 注文を閲覧できる範囲は、役割や支店に関係なく **会社単位** です。医療機関が貴社に閲覧を許可した注文だけが表示されます。
