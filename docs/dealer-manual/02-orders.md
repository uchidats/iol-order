# 2. 受注一覧

医療機関からの注文のうち、貴社宛ての明細を確認する画面です。

---

## 1. 表示される注文

- 医療機関（施設）の管理者が **貴社に閲覧を許可した後** の、新しい注文が対象です。許可より前の注文は表示されません。
- 1つの注文に複数のディーラー宛ての明細がある場合も、**貴社宛ての明細だけ** を表示します（他社宛ての明細・共通の備考などは表示されません）。
- 閲覧できる範囲は会社単位です。役割・支店による違いはありません。
- 新しい注文は、注文メールとは別に反映されるため、表示まで少し時間がかかることがあります。

---

## 2. 医療機関の選択

画面上部の **「医療機関」** の枠で、表示する医療機関をチェックします。

- チェックの内容は **この端末（ブラウザ）に自動で記憶** され、次回も同じ選択で開きます。別の端末では、その端末での選択になります。
- **すべてのチェックを外した状態** も、そのまま記憶されます（注文は表示されません）。
- **「担当」** の印は、会社の管理者が登録した貴方の **担当施設** です。初めて開いたときは担当施設が選択されます（担当施設がない場合は、閲覧できるすべての医療機関）。
- 医療機関が2件以上ある場合は、次のボタンで一括で選択できます。
  - **「担当施設のみ」**（担当施設があるときだけ）・**「すべて選択」**・**「すべて解除」**
- チェックを変えても、担当施設の登録や閲覧できる範囲は変わりません。担当施設の変更は、会社管理者・支店管理者が「[ディーラー設定](./03-settings.md)」で行います。

---

## 3. 表示の切り替え

医療機関の枠の下にある **「手術週」／「一覧表示」** で表示を切り替えます。

### 手術週

- 初めは **今週（月曜〜日曜）** に手術予定の明細を、手術日ごとに表示します。
- **「← 前週」「今週」「翌週 →」** で週を移動します。
- 明細ごとに、医療機関・メーカー・IOLモデル・度数・枚数を表示します。同じ注文にほかの手術日の明細がある場合は、その旨を示します。
- 注文番号・注文日時は、明細を押すと表示される **受注詳細** で確認できます。

### 一覧表示

- 注文を **注文日時の新しい順** に20件ずつ表示します。続きは **「もっと見る」** で表示します。
- 行ごとに、医療機関・担当医・件数・合計枚数を表示します。注文番号・注文日時は、行を押すと表示される **受注詳細** で確認できます。
- **「絞り込み」** を開くと、**注文日（開始日と終了日の両方）** と **注文番号（完全一致）** で絞り込めます。**「この条件で表示」** で検索し、**「条件をクリア」** で戻します。
- 一覧は「この条件で表示」を押した時点の内容です。「もっと見る」の続きも同じ時点の内容です。その後に反映された注文は、もう一度「この条件で表示」を押すと表示されます。
- 件数は一覧のすぐ上に表示されます。

---

## 4. 受注詳細

一覧の行を押すと、受注詳細を表示します。**「← 一覧へ戻る」** で一覧に戻ります。

- 医療機関・注文番号・注文日時・自社宛ての件数と合計枚数、明細（メーカー・モデル、トーリック型番、度数、枚数、手術日、担当医）を表示します。
- **注文メールの状態** は、通常（送信済み）の場合は表示しません。送信待ち・送信できなかった・配信できなかったなど、**注意が必要な場合だけ** 表示します。
- 見出し「受注詳細」の右の **ⓘ** で、注文メールの詳しい状況を確認できます。
- 注文メールの状態は送信・配信の状況で、受注の確定を示すものではありません。

---

## 5. 画面の説明（ⓘ）

見出しの右の **ⓘ** を押す（パソコンではマウスを重ねる）と、その項目の説明が表示されます。外側を押すか、Esc キーで閉じます。
