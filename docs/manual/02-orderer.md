# 2. 注文者・代理入力者向け（IOL注文・注文履歴・重複注文警告）

IOLの注文入力、重複注文の防止機能、および注文履歴の確認方法を説明します。  
（※ログインや施設の切り替えについては **[1. 初めて利用する方へ](./01-first-time.md)** をご覧ください。）

---

## 1. 「注文者」と「代行入力者（代理入力者）」の違い

どちらの役割も、IOLの注文と注文履歴の閲覧が可能です。

| 項目 | 注文者 | 代行入力者（代理入力者） |
| :--- | :--- | :--- |
| **主な対象** | 医師ご本人 | 医師の指示を受けて入力するスタッフ等 |
| **担当医の初期値** | 担当医マスターに同じメールアドレスが登録されていれば、**ご自身が自動選択**されます（変更も可能） | 未選択の状態から、該当する **担当医を選択** します |
| **注文履歴の表示** | 「発注者 〇〇」と記録されます | 一覧に「〇〇（代行入力）」、詳細に「入力者 〇〇（代行入力者）」と記録され、明細ごとの「担当医」と区別されます |

## 2. IOLを注文する

### 手順1：レンズの条件を入力する
「レンズ1」カードの各項目を選択します（`*` は必須項目です）。

1. **種類の絞り込み（任意）**
   - **「トーリック」**・**「多焦点」** にチェックを入れると、該当するレンズだけにIOLモデルの選択肢が絞り込まれます。
2. **IOLモデル（必須）**
   - 施設で採用されているIOLから選択します。
3. **IOLパワー（必須）**
   - 選択したIOLモデルで選べる度数（ディオプター）から選択します。
   - ※安全のため、度数は自動選択されません。必ず実測値・計算結果をご確認のうえ選択してください。
4. **枚数（必須）**
   - **「1 枚」** または **「2 枚」** を選択します（初期値は「1 枚」）。
5. **手術日（必須）**
   - 本日〜1年以内の日付を指定します（過去の日付は選択できません）。
6. **担当医（必須）**
   - 施設の担当医リストから選択します。
7. **発注先（施設にディーラーが2社以上登録されている場合のみ表示・必須）**
   - 発注先のディーラーを選択します。
   - 施設で IOLモデルごとに **既定の発注先** が設定されている場合は、IOLモデルを選んだときに自動で選ばれます（変更できます）。別のIOLモデルに変えると、そのモデルの既定の発注先に切り替わります（既定がないモデルでは未選択に戻るので、選び直してください）。度数・枚数・手術日を変えても発注先は変わりません。
   - ※施設の登録ディーラーが **1社のみ** の場合は自動選択されるため入力欄は表示されません。**0社** の場合は「発注先未設定」となります。

### 手順2：複数のレンズをまとめて注文する場合（任意）
1. **「＋ レンズを追加」** をタップすると、入力カード（レンズ2、レンズ3…）が追加されます。
   - 1回の注文で **最大20件（合計40枚）** までまとめて発注できます。
   - 追加したカードには、直前のレンズの **「手術日」「担当医」「発注先」** が自動で引き継がれます（個別に変更可能です）。
   - 入力が済んだレンズは、追加のときに自動で **折りたたまれ**、「手術日・担当医」と「メーカー・モデル・度数・枚数」だけの簡潔な表示になります。直前のレンズも折りたたまれていて、手術日・担当医が同じ場合は、「メーカー・モデル・度数・枚数」の1行だけになります（未入力や入力に誤りがあるレンズは折りたたまれません）。
   - 折りたたまれたカードをタップすると展開され、内容を修正できます。カード上部の「レンズ番号」のすぐ右にある **矢印アイコン** でも、折りたたみ・展開を切り替えられます。
2. **レンズを削除・元に戻す場合**
   - 各レンズカード右上の **ゴミ箱アイコン** をタップすると削除されます（1枚目の場合は入力内容がクリアされます）。折りたたまれているカードは、展開するとゴミ箱アイコンが表示されます。
   - 誤って削除した場合は、画面下部に表示される通知の **「元に戻す」** をタップすると元の状態に戻せます。

### 手順3：備考の入力・Calculatorリンク（任意）
- **備考（フリーコメント）**：特記事項などがあれば入力します（1000文字以内）。
- **各社 Calculator 関連リンク**：タップして開くと、各メーカーのトーリック計算ツールや ESCRS IOL calculator を別タブで開けます。

### 手順4：確認画面へ進み、注文を送信する
1. **「注文内容を確認」** をタップします。
   - 過去の注文と重複するレンズがある場合は、確認画面の前に警告が表示されます（後述「3. 重複注文警告について」参照）。
2. **「注文内容の確認」** 画面で内容を確認します。
   - レンズ明細は **「手術日 ＋ 担当医（〇〇Dr）」** ごとに整理して表示されます。
   - 下部の **「発注元」**（施設名）と **「発注先」**（ディーラー名）に間違いがないか確認します。
   - ※発注先ディーラーに発注用メールアドレスが未登録の場合などは、発注先の下に注意書きが表示されます。
   - 1回の注文に **複数のディーラー** 宛てのレンズが含まれる場合は、ディーラーごとに内容（レンズ明細・件数と合計枚数・備考・発注元と発注先）を分けて縦に並べて表示します。下へスクロールしてすべてのディーラー分を確認してください。レンズの番号は入力時の番号のままで、最後に注文全体の件数・合計枚数が表示されます。
3. **「注文を送信」** をタップします。
   - 修正したい場合は **「戻って修正」** をタップします。
4. **「注文を受け付けました」** 画面が表示され、**受付番号**（例：`IOL-20261027-01`）が発行されたら完了です。
   - 続けて別の注文を入力する場合は **「新しい注文を入力する」** をタップします。

> **下書きの自動保存について**  
> 入力途中の内容は、お使いの端末（ブラウザ）にログインユーザー・施設ごと自動で下書き保存されます。誤って画面を閉じたり再読み込みしたりしても、「入力途中の内容を復元しました」と表示され続きから入力できます（注文送信が完了すると下書きは消去されます）。

## 3. 重複注文警告について（二重発注の防止）

誤って同じレンズを重複して発注することを防ぐため、2段階のチェック機能があります。

### ① 過去の注文との重複警告
**「注文内容を確認」** をタップした際、施設内の過去の発注済み注文（最新最大300件）と照合します。

- **一致と判定する条件**
  - **「IOLモデル（トーリック型番含む）・IOLパワー・手術日・担当医」** の4項目がすべて一致する場合（枚数は問いません）。
- **表示と操作**
  - 一致するレンズがあると、**「過去の注文と一致するレンズが○件あります」** という警告画面が表示され、対象レンズと「過去の注文日」が一覧表示されます。
  - 内容を見直す場合は **「注文内容を修正」**、別患者・追加発注などで間違いなければ **「確認して続行」** をタップして確認画面へ進みます。

### ② 同じ注文内の重複確認
1回の注文の中で、**「同じ手術日・担当医・IOLモデル・IOLパワー」** の明細が複数含まれている場合、注文確認画面の下部に黄色の確認欄が表示されます。

- そのままでは「注文を送信」ボタンを押せません。
- 内容を確認し、意図した注文であれば **「重複を確認しました」** にチェックを入れると **「注文を送信」** が押せるようになります。

## 4. 通信エラー・タイムアウト時のご注意

「注文を送信」をタップした後に通信エラーやタイムアウトが発生し、「受付結果を確認できませんでした」と表示された場合：

- **同じ端末からそのまま再送信する場合**
  - 入力内容は保持されています。そのまま同じ端末で再送信すると、サーバー側で同一の注文として認識されるため、**二重に注文が登録されることはありません**。
- **別の端末から注文し直す場合**
  - 再入力する前に、必ず **「注文履歴」** を開き、直前の注文がすでに受け付けられていないか確認してください。

---

## 5. 注文履歴を確認する

施設全体の注文状況や、ディーラーへのメール送信結果をいつでも確認できます。

1. 画面右上のメニュー（**`≡`**）→ **「注文履歴」** をタップします。
2. 選択中の施設の注文が、新しい順に **最大50件** 表示されます。
   - 各行には「注文日時」「発注者（または代行入力者）」「件数・合計枚数」が表示されます。
3. 確認したい注文の行をタップすると、詳細画面が開きます。
   - **確認できる内容**：受付番号、注文日時、発注者（または入力者と役割）、注文全体の状態、各レンズ明細（モデル・度数・枚数・手術日・担当医・発注先）、備考、**メール送信状況**（発注先ごとの送信受付・配信済み・配信失敗などの結果と日時）。
4. 一覧に戻るには **「← 一覧へ戻る」**、注文フォームに戻るには右上の **「注文画面に戻る」** をタップします。

> **ご注意**  
> 注文履歴は閲覧専用です。送信済みの注文を画面から変更・キャンセルしたり、失敗したメールを画面から手動で再送信したりすることはできません。メール送信が「送信失敗」や「配信失敗」となっている場合は、ディーラーへ電話等で直接ご連絡ください。
