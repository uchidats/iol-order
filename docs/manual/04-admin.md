# 4. 施設管理者向け（施設管理・利用者の権限変更・招待・削除）

施設の最高権限である **「管理者（施設管理者）」** 向けの操作マニュアルです。  
管理者は、IOL注文や副管理者のすべての設定に加え、**すべての役割（管理者・副管理者を含む）の利用者管理**、**施設名の変更**、および **施設の削除** を行うことができます。

- ログイン・施設登録申請については **[1. 初めて利用する方へ](./01-first-time.md)** をご覧ください。
- IOL注文・注文履歴については **[2. 注文者・代理入力者向け](./02-orderer.md)** をご覧ください。
- 担当医・採用IOL・ディーラー・注文メール・テーマカラーの設定については **[3. 副管理者向け](./03-subadmin.md)** をご覧ください。

---

## はじめに：最初の管理者になったら

施設の登録申請が承認された方や、施設の最初の管理者として参加した方は、次の順に施設の初期設定を行ってください。いずれも画面右上のメニュー（**`≡`**）→ **「施設設定」** で行います（詳しい操作は **[3. 副管理者向け](./03-subadmin.md)** をご覧ください）。

1. **担当医** を登録する
2. **採用IOL** を選ぶ
3. **ディーラー（発注先）** と発注用メールアドレスを登録する
4. **注文メール**（署名・注文控え）を設定する
5. 必要に応じて、施設で使う方を **利用者** として招待する（このページの「2. 利用者を招待（事前登録）する」）

- 施設名は、申請した名称（または運営者が登録した名称）になっています。変更する場合は「5. 施設名を変更する」をご覧ください。
- 注文の受付の開始については、IOL Order 運営者からご連絡します。

---

## 1. 利用者の4つの役割と権限

施設設定の **「利用者管理」** では、利用者に以下の4つの役割を設定できます。

| 役割 | 主な対象者 | できること |
| :--- | :--- | :--- |
| **管理者** | 院長・施設責任者 | すべての操作（施設設定、全メンバーの招待・権限変更・削除、施設名の変更、施設の削除） |
| **副管理者** | 師長・視能訓練士主任・事務長など | IOL注文・履歴閲覧、施設設定（担当医・採用IOL・ディーラー・注文メール・テーマカラー）、**注文者・代行入力者** の招待・変更・削除 |
| **注文者** | 執刀医・担当医 | IOL注文（担当医に自分が初期選択される）・注文履歴の閲覧 |
| **代行入力者** | 検査スタッフ・クラークなど | IOL注文（担当医を選択して代理入力）・注文履歴の閲覧 |

---

## 2. 利用者を招待（事前登録）する

新しいスタッフや医師を施設に招待する手順です。

1. 画面右上のメニュー（**`≡`**）→ **「施設設定」** を開きます。
2. **「利用者管理」** セクション見出し右側の **「追加」** をタップします。
3. **「名前」**（50文字以内）と **「メールアドレス」** を入力します。
4. 役割を **「副管理者」「注文者」「代行入力者」** から選択し、**「登録」** をタップします。
   - **別の人を「管理者」にしたい場合**：事前登録時の選択肢には「管理者」はありません。まずは「副管理者」などで登録し、本人がログインして参加を承諾した後に、次の「3. 利用者の権限（役割）を変更する」の手順で「管理者」に変更してください。
5. 登録した本人に、指定したメールアドレスで IOL Order にログインし、確認画面で **「参加する」** を押すよう案内します（有効期限は登録から **30日間** です）。

### 参加待ちメンバーの管理
本人が参加を承諾するまでの間、一覧には状態バッジ（**`参加待ち` / `期限切れ` / `辞退`**）が表示されます。

- **内容の修正**：**鉛筆アイコン** をタップすると、名前・メールアドレス・役割を変更できます（※メールアドレスを変更すると、変更前のアドレスでは参加できなくなります）。
- **有効期限の延長（再登録）**：「期限切れ」または「辞退」になった行に表示される **「再登録」** をタップすると、再び30日間有効な「参加待ち」に戻ります。
- **招待の取り消し**：**ゴミ箱アイコン** をタップすると登録を取り消せます。

## 3. 利用者の権限（役割）を変更する

参加済みのメンバーの役割（管理者／副管理者／注文者／代行入力者）を変更できます。

1. 「施設設定」→ **「利用者管理」** を開きます。
2. 対象メンバーの名前の横にある **役割バッジ（例：`副管理者 ▾`、`注文者 ▾`）** をタップします。
3. 変更後の役割を選択し、**「変更」** をタップします。
   - **「管理者」** に変更する場合は、確認ダイアログが表示されます。内容を確認してOKを押してください。

### 権限変更の制限（安全上のルール）
- **自分自身の役割は変更できません**：誤って管理者権限を失うことを防ぐため、自分の行の役割バッジは変更できません。
- **最後の1人の管理者は降格できません**：施設には最低1人の「管理者」が必要です。現在の管理者が別の人に管理者を引き継ぐ場合は、**先に新しい管理者を「管理者」に変更してから**、新しい管理者に自分の役割変更を依頼してください。

---

## 4. 利用者を削除する（所属の解除）

退職や異動などで、施設からメンバーの所属を外す手順です。

1. 「施設設定」→ **「利用者管理」** を開きます。
2. 対象メンバーの行の **ゴミ箱アイコン** をタップします。
3. 確認ダイアログでOKを押すと、その施設からの所属が削除されます。
   - 削除された利用者は、ただちにこの施設の注文画面や設定を開けなくなります（過去の注文履歴の記録は残ります）。

### 削除できない場合の対処法
- **「管理者」のままでは削除できません**（ゴミ箱アイコンが表示されません）
  - 誤削除防止のため、役割が「管理者」のメンバーは直接削除できません。先に役割バッジをタップして **「副管理者」や「注文者」などに役割を変更してから**、ゴミ箱アイコンで削除してください（施設に他の管理者がいる必要があります）。
- **自分自身の所属は削除できません**
  - ご自身の所属を外す場合は、他の管理者に削除を依頼してください。

---

## 5. 施設名を変更する

施設の名称表記を変更したい場合の手順です。

1. 「施設設定」画面の上部（施設名の右側）にある **鉛筆アイコン（施設名を編集）** をタップします。
2. 新しい **「施設名」**（1〜100文字）を入力し、**「変更する」** をタップします。
   - すでに登録されている他の施設と名前が似ている場合は確認メッセージが表示されます。別の施設として間違いなければ **「別の施設として変更する」** をタップしてください。
3. 施設名を変更しても、施設のID、所属メンバー、各種設定、過去の注文履歴はすべてそのまま引き継がれます。

---

## 6. 施設を削除する

誤って作成した施設などを削除する手順です。

1. 「施設設定」画面の上部（施設名の右側）にある **ゴミ箱アイコン（施設を削除）** をタップします。
2. 「施設の削除」ダイアログで対象施設名を確認し、**「この施設を削除する」** をタップします。

> **重要：施設を削除できる条件と注意点**  
> 医療データの保全と誤操作防止のため、以下の条件をすべて満たす施設のみ削除できます。
> - **注文履歴が1件もないこと**（1件でも注文がある施設は削除できません）
> - **自分以外の所属メンバーがいないこと**（他のメンバーがいる場合は、先に「利用者管理」から全員の所属を削除してください）
>
> ※施設を削除すると、登録した担当医・採用IOL・ディーラー・参加待ちの招待などがすべて消去され、**元に戻すことはできません**。
