# 3. 副管理者向け（担当医・利用者・採用IOL・ディーラー・注文メール・テーマカラーの設定）

施設の「副管理者」が行える施設設定の操作方法を説明します。  
（※これらの設定は「管理者」も同様に行えます。ログイン方法は **[1. 初めて利用する方へ](./01-first-time.md)**、IOLの注文方法は **[2. 注文者・代理入力者向け](./02-orderer.md)** をご覧ください。）

---

## 1. 施設設定画面の開き方と基本操作

1. 画面右上のメニュー（**`≡`**）→ **「施設設定」** をタップします。
2. 設定が終わったら、画面右上の **「注文画面に戻る」** をタップします。

### 画面の便利な機能
- **セクションの折りたたみ**：各設定項目の見出しをタップすると、セクションを開閉できます（開閉状態はお使いの端末に記憶されます）。
- **説明の表示（`ⓘ`）**：見出し横の **`ⓘ`** をタップすると、その項目の詳しい説明が表示されます。
- **自動保存**：チェックの変更や並び替えは **自動で保存** されます。担当医やディーラーの行編集は、行内の **「保存」** ボタンを押した時点で保存されます。

---

## 2. 担当医の設定

注文フォームの「担当医」の選択肢を管理します。

### 担当医を追加する
1. 「担当医」見出し右側の **「追加」** をタップします。
2. **「氏名（必須）」**（50文字以内）と **「メールアドレス（任意）」** を入力します。
   - **メールアドレスを登録するメリット**：その医師が同じメールアドレスでログインした際、注文フォームの「担当医」に本人が初期選択されるようになります。
   - **「利用者管理にも追加する（注文者）」**：まだ施設に所属していないメールアドレスを入力すると、このチェックボックスが表示されます。チェックを入れて保存すると、担当医マスターへの登録と同時に、施設の利用者（注文者）としても事前登録（招待）できます。
3. **「保存」** をタップします。

### 編集・並び替え・削除する
- **編集**：各行の **鉛筆アイコン** をタップして修正し、**「保存」** をタップします。
- **並び替え**：**`↑`** ボタンをタップすると1つ上へ移動し、注文フォームでの表示順が変わります（自動で保存されます）。
- **削除**：**ゴミ箱アイコン** をタップし、確認画面でOKを押すと削除されます（過去の注文履歴に記録された担当医名は消えません）。

---

## 3. 利用者管理（注文者・代行入力者の管理）

副管理者は、施設で注文を行う **「注文者」** と **「代行入力者」** の追加・編集・削除を行えます。  
（※「管理者」「副管理者」の追加・権限変更・削除は施設管理者のみ可能です。**[4. 施設管理者向け](./04-admin.md)** を参照してください。）

### 利用者を招待（事前登録）する
1. 「利用者管理」見出し右側の **「追加」** をタップします。
2. **「名前」**、**「メールアドレス」** を入力し、役割（**「注文者」** または **「代行入力者」**）を選択して **「登録」** をタップします。
3. 一覧に **「参加待ち」**（登録から30日間有効）として追加されます。
4. 登録した本人に、そのメールアドレスで IOL Order にログインし「参加する」を押すよう案内してください。

### 参加待ち・参加済みメンバーの操作
- **氏名の編集**：各行の **鉛筆アイコン** をタップして変更し、**「保存」** をタップします（参加待ちの間はメールアドレスと役割も編集可能です。自身の氏名も変更できます）。
- **役割の変更（注文者 ⇔ 代行入力者）**：参加済みメンバーの名前の横にある **役割バッジ（`注文者 ▾` / `代行入力者 ▾`）** をタップし、役割を選んで **「変更」** をタップします。
- **再登録（期限切れ・辞退の場合）**：30日を過ぎて「期限切れ」になった場合や「辞退」された場合は、行内の **「再登録」** ボタンで有効期限を30日間延長できます。
- **削除（取消）**：**ゴミ箱アイコン** をタップすると、参加待ちの取り消し、または参加済みメンバーの所属削除ができます。
- **並び替え**：**`↑`** ボタンで一覧の表示順を並び替えられます。

## 4. 採用IOLの設定

施設で使用するIOLモデルと、注文フォームでの表示順を設定します。

1. 「採用IOL」セクションで、メーカー名をタップして一覧を開きます。
   - メーカー名の横には `採用数/登録数`（例：`3/8`）が表示されます。
2. 施設で使用するIOLモデルに **チェック** を入れます。
   - チェックしたモデルだけが注文フォームの選択肢に表示されます。
   - チェックを外すと注文フォームから非表示になります（過去の注文履歴には影響しません）。
3. **表示順の変更**：メーカー見出しの **`↑`** でメーカー順を、各IOLモデルの **`↑`** でメーカー内のモデル順を並び替えられます。
   - 選択や並び替えはすぐに自動保存されます。

## 5. ディーラー（発注先）の設定

発注先ディーラーの名称とメールアドレスを登録します。

### ディーラーの登録数と注文フォームの動き
- **0社（未登録）**：注文は「発注先未設定」として保存されます（ディーラーへのメール送信は行われません）。
- **1社のみ登録**：注文フォームでその1社が **自動選択** されます（注文時の選択操作は不要です）。
- **2社以上登録**：注文フォームの明細ごとに **「発注先」の選択が必須** になります。

### ディーラーを追加・編集する
1. 「ディーラー」見出し右側の **「追加」**（または既存行の **鉛筆アイコン**）をタップします。
2. 各項目を入力します：
   - **ディーラー名（必須・100文字以内）**：注文画面や履歴に表示される名称です。
   - **注文メールの宛名（任意・100文字以内）**：注文メール本文の先頭（「〇〇御中」）に使う正式表記です。未入力の場合は「ディーラー名」が使われます。
   - **発注用メールアドレス（最大5件）**：注文メールの送信先です。複数ある場合は改行（1行に1件）で入力します。
     - ※**発注用メールアドレスが未登録の場合、注文メールは自動送信されません**（一覧に `発注用メール未登録(自動送信不可)` と表示されます）。
   - **使用報告用メールアドレス（最大5件）**：使用報告用の連絡先を控えておく欄です（※注文メールはこのアドレスには送信されません）。
3. **「保存」** をタップします。
4. **`↑`** ボタンで選択肢の並び替え、**ゴミ箱アイコン** で削除が行えます（削除しても過去の注文履歴のディーラー名は残ります）。

## 6. 注文メールの設定

ディーラーへ送信される注文メールの「署名」と、施設側で受け取る「注文控えメール」を設定します。変更は自動で保存されます。

### 注文控えメールを送信する
1. **「注文控えメールを送信する」** にチェックを入れます。
2. 表示された **「注文控えの送信先（1件）」** に施設のメールアドレスを入力します。
   - ディーラー宛てメールの送信処理が終わった後に、**ディーラーへの送信状況（受付・失敗・未送信）と注文内容の控え** がこのアドレスに届きます。
   - また、ディーラー宛て注文メールの返信先（Reply-To）にも、注文入力者本人のアドレスに加えてこのアドレスが設定されます。

### 署名
- **「署名」** 欄に、施設名・郵便番号・住所・電話番号などを入力します（最大10行・500文字まで）。
- 入力した内容は、ディーラーへ送られる注文メール本文の末尾にそのまま記載されます。

## 7. テーマカラーの設定

画面上部（ヘッダー）の色を施設ごとに変更できます。複数の施設を兼務している方が、現在開いている施設を一目で判別したい場合にも便利です。

1. 「テーマカラー」セクションで、**色見本**（白文字向け10色・黒文字向け10色）から好きな色をタップします。
   - **「その他の色」** からカラーピッカーやカラーコード（`#RRGGBB` 形式）で自由な色を指定することもできます。
2. 必要に応じて以下のチェックを調整します：
   - **「グラデーションを使用する」**：ヘッダー背景にグラデーションをつけます（初期値はON）。
   - **「フォントを黒にする」**：明るい背景色を選んだ場合に、ヘッダーの文字色を黒にします（色見本の「黒文字向け」を選んだ場合は自動でONになります）。
3. 選択するとすぐに画面上部のヘッダーに反映され、自動で保存されます。
4. 標準の青いヘッダーに戻したい場合は **「初期設定に戻す」** をタップします。
