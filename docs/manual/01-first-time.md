# 1. 初めて利用する方へ（ログイン・施設登録申請・招待参加）

**IOL Order**（https://iol.medconf.jp/）を初めて利用する方向けに、ログインから施設への参加・新規登録申請までの手順を説明します。

---

## 1. サイトを開く・共有する

1. スマートフォンまたはパソコンのブラウザで `https://iol.medconf.jp/` を開きます。
2. 他のスタッフや別の端末にURLを共有したい場合は、画面右上のメニューボタン（**`≡`**）→ **「サイトを共有」** をタップします。
   - QRコードの読み取り、または **「URLをコピー」** ボタンで簡単に共有できます（ログイン前でも利用可能です）。
3. 操作に迷ったときは、メニュー（**`≡`**）→ **「使い方・ヘルプ」** でこのマニュアルを開けます（ログイン前でも閲覧できます）。

---

## 2. ログインする

IOL Order の利用にはログインが必要です。パスワードの登録・管理は不要です。

### A. Googleアカウントでログインする場合
1. **「Googleでログイン」** をタップします。
2. 使用するGoogleアカウントを選択してログインします。

### B. メールアドレスでログインする場合
1. 「メールでログイン（パスワード不要）」欄にメールアドレスを入力します。
2. **「ログインリンクを送信」** をタップします。
3. 届いたメール内のログインリンクを開くとログインが完了します。
   - **ご注意**：メールを開いた端末が送信時と異なる場合は、確認のためもう一度メールアドレスの入力を求められます。

> **重要：メールアドレスの確認について**  
> 施設の登録や参加には、メールアドレスの確認（認証）が済んでいるアカウントが必要です。

---

## 3. 既存の施設に招待されて参加する

すでに IOL Order を利用している施設に参加する場合、**招待コードの入力は不要**です。

### 事前準備（施設の管理者・副管理者が行う操作）
- 施設の「管理者」または「副管理者」に、あなたの **名前** と **ログインに使うメールアドレス** を伝え、「施設設定」の「利用者管理」に登録してもらいます（登録から30日間有効）。

### 参加の手順（本人が行う操作）
1. 登録してもらったメールアドレスで IOL Order にログインします。
2. **「施設への参加の確認」** 画面が自動的に表示されます。
   - すでにログイン中だった場合は、ブラウザのページを再読み込みしてください。
3. 表示された **施設名** と **役割**（管理者／副管理者／注文者／代行入力者）を確認し、**「参加する」** をタップします。
   - 身に覚えがない場合は **「参加しない」** をタップしてください。
4. すぐにその施設の注文画面が利用できるようになります。

### 施設の最初の管理者として参加する場合
次のような場合は、あなたが施設の最初の **「管理者」** として登録されています。

- IOL Order 運営者が施設をあらかじめ登録し、あなたを管理者に指定した場合（ログインに使うメールアドレスと利用開始の方法は、運営者からご連絡します）
- 施設の登録申請が承認される際に、申請者とは別の責任者としてあなたが指定された場合（**「【IOL Order】施設の管理者としての参加のご案内」** という件名のメールが届きます）

参加の手順は次のとおりです。

1. 指定されたメールアドレスで IOL Order にログインします。
2. **「施設への参加の確認」** 画面に、施設名と **「参加すると、この施設の管理者になります」** という説明が表示されます。
3. 施設名を確認し、**「参加する」** をタップします。
   - 参加した時点で施設が利用できる状態になり、あなたがその施設の管理者になります。参加するまで、管理者の権限は付きません。
   - 参加の期限は、登録（申請の承認）から **30日間** です。期限が過ぎた場合や、誤って「参加しない」を選んだ場合は、IOL Order 運営者にお問い合わせください。
   - 心当たりがない場合は **「参加しない」** をタップしてください。
4. 参加後は、**[4. 施設管理者向けマニュアル](./04-admin.md)** の「はじめに：最初の管理者になったら」を参考に、施設の初期設定を行ってください。

---

## 4. 新しい施設を登録申請する

自施設で初めて IOL Order を導入する場合は、施設の登録申請を行います。

> **※既存施設に参加する方へ**  
> すでにある施設に参加したい場合は、ここから新規申請せず、「3. 既存の施設に招待されて参加する」の手順で施設の管理者にご依頼ください。

### 申請の手順
1. ログイン後、どの施設にも所属していない場合は自動的に **「施設への所属が確認できません」**（新しい施設の登録）画面が表示されます。
   - すでに別の施設に所属している方が追加で新しい施設を申請する場合は、画面右上のメニュー（**`≡`**）→ **「新しい施設を登録」** をタップします。
2. **「施設名」**（1〜100文字）を入力します。
   - 2文字以上入力すると、すでに登録されている似た名前の施設がないか自動で確認されます。
3. **「申請者のお名前」**（1〜50文字）を確認・入力します。
4. **「申請する」** をタップします。
   - 既存施設と名前が重なる候補がある場合は確認メッセージが表示されます。別の施設として間違いなければ **「別の施設として申請する」** をタップしてください。

### 申請後の流れ（運営者による承認制）
- 施設の登録は **IOL Order 運営者の承認制** です。
- 申請直後は「審査中」となり、承認されるまで注文機能は利用できません。
- 審査の結果は、ログインに使ったメールアドレス宛てに **メールでお知らせ** します（送信専用のメールのため、返信はできません）。

#### 承認された場合
- 件名 **「【IOL Order】施設登録の申請が承認されました」** のメールが届きます。
- 施設が有効になり、申請者が最初の **「管理者」** として登録されます。ページを再読み込み（またはログイン）すると利用を開始できます。
- 最初に施設設定（担当医・採用IOL・ディーラー・注文メール）を行ってください（**[4. 施設管理者向けマニュアル](./04-admin.md)** の「はじめに：最初の管理者になったら」）。
- 注文の受付の開始については、IOL Order 運営者からご連絡します。

#### 申請者とは別の方が最初の管理者に指定された場合
- 申請の内容によっては、運営者が施設の責任者など、申請者とは別の方を最初の管理者に指定することがあります。
- その場合、申請者へのメールにその旨が記載され、指定された方には別に **参加のご案内メール** が届きます。指定された方が参加すると、施設を利用できるようになります（手順は「3. 既存の施設に招待されて参加する」の「施設の最初の管理者として参加する場合」）。
- 申請者には、この施設の管理者の権限は付きません。施設を利用する場合は、参加した管理者に利用者の登録を依頼してください。

#### 承認が見送られた場合
- 件名 **「【IOL Order】施設登録の申請の結果」** のメールが届きます。施設は登録されません。
- 運営者の判断により、メールに理由が記載される場合があります。
- 内容を確認のうえ、必要に応じて改めて申請してください。既存の施設に参加する場合は、その施設の管理者に利用者の登録を依頼してください。

> **メールが届かない場合**  
> 迷惑メールフォルダもご確認ください。申請者が最初の管理者として承認されている場合は、メールが届かなくても、ページを再読み込み（またはログイン）すると施設を利用できます。

## 5. 施設の選択・切り替え・ログアウト

### 複数の施設に所属している場合
- ログイン時に **「施設を選択してください」** 画面が表示されます。利用する施設をタップして選択してください（前回選択した施設が記憶されます）。
- 施設の位置情報が設定されている場合は、**「現在地から施設を選ぶ」** ボタンで現在地に近い施設を自動選択できます（位置情報は端末内でのみ照合され、サーバーには送信・保存されません）。

### 利用中に施設を切り替える
1. 画面右上のメニュー（**`≡`**）→ **「施設を切り替える」** をタップします。
   - 注文フォームに入力途中の内容がある場合は、破棄の確認ダイアログが表示されます。
2. 切り替え先の施設を選択します。

### ログアウトする
- 画面右上のメニュー（**`≡`**）→ **「ログアウト」** をタップします。
