# IOL Order オンラインマニュアル

眼内レンズ（IOL）発注システム **IOL Order**（https://iol.medconf.jp/）の操作マニュアルです。  
スマートフォン・パソコンのどちらからでもご利用いただけます。  
このマニュアルは、画面右上のメニュー（**`≡`**）→ **「使い方・ヘルプ」** からいつでも開けます（ログイン前でも閲覧できます）。

---

## マニュアル一覧

ご自身の立場や目的に合わせてご覧ください。

1. **[初めて利用する方へ](./01-first-time.md)**
   - ログイン方法（Googleログイン・メールリンク）
   - 招待された施設への参加手順
   - 施設の最初の管理者として参加する場合（運営者があらかじめ登録した施設・申請の承認時に指定された場合）
   - 新しい施設の登録申請と、審査結果のお知らせメール
   - 施設の切り替え・サイトの共有（QRコード）

2. **[注文者・代理入力者向け](./02-orderer.md)**
   - 注文者と代行入力者（代理入力者）の違い
   - IOLの注文手順・レンズの追加と削除
   - 下書きの自動保存
   - 重複注文警告（過去の注文との照合・同一注文内の重複確認）
   - 注文履歴の確認・通信エラー時の注意点

3. **[副管理者向け](./03-subadmin.md)**
   - 施設設定の基本操作（折りたたみ・自動保存）
   - 担当医の登録・編集・並び替え
   - 利用者管理（注文者・代行入力者の追加と管理）
   - 採用IOLの選択・表示順の設定
   - ディーラー（発注先）の登録
   - 注文メール（注文控え・署名）の設定
   - テーマカラー（ヘッダー色）の設定

4. **[施設管理者向け](./04-admin.md)**
   - 利用者の役割（権限）一覧
   - 最初の管理者になったときの初期設定
   - 利用者（副管理者・注文者・代行入力者）の招待（事前登録）・再登録・取消
   - 利用者の権限（役割）変更・管理者の追加と交代
   - 利用者の所属削除
   - 施設名の変更・施設の削除

## 利用者の役割（権限）早見表

施設に所属する利用者には、以下の4つの役割のいずれかが割り当てられます。

| 役割（画面表記） | IOL注文・注文履歴の閲覧 | 施設設定（担当医・採用IOL・ディーラー・メール・テーマ） | 利用者管理（注文者・代行入力者） | 利用者管理（管理者・副管理者） | 施設名の変更・施設の削除 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **管理者** | ○ | ○ | ○ | ○ | ○ |
| **副管理者** | ○ | ○ | ○ | × | × |
| **注文者** | ○（※1） | × | × | × | × |
| **代行入力者**（代理入力者） | ○（※2） | × | × | × | × |

- **※1 注文者**：担当医に自身のメールアドレスが登録されている場合、注文画面で「担当医」に自分が初期選択されます。
- **※2 代行入力者**：医師に代わってスタッフ等が注文を入力する役割です。注文履歴には「入力者（代行入力者）」として記録され、明細ごとの「担当医」と区別して表示されます。
