## 変更内容
### 並び替えボタン(PC・スマホ共通)
- 担当医・ディーラー・採用IOL(メーカー・メーカー内のIOL)の並び替えを、**「↑」のみ**に統一。**「↓」は廃止**(先に依頼された「スマホだけ↑のみ」は、この統一仕様に置き換え)。
- **各リストの先頭の「↑」は見えなく・押せなく**するが、**場所は残す**(`visibility:hidden`。ほかのボタンの位置が行ごとにずれない。画面テストで、↑・編集・削除の左端が全行でそろうことを確認)。並び替え・追加・削除のたびに更新。
- 担当医・ディーラーのボタンの順は、左から **「↑」「編集(鉛筆)」「削除(ゴミ箱)」**。採用IOLは「↑」のみ。ボタンのサイズ・色・間隔は既存のまま。ボタンが減った分、名前・型番の表示幅が広がる。
- 並び替え後の自動保存・編集・削除の機能は変更なし。既存データ・並び順も変更なし。
- 不具合の修正: 「↑」の表示切り替えが、ボタンの `transition: all`(0.15秒)で遅れて見えていたため、表示・非表示だけは即時に切り替わるようにした。
### 見出し
- 「施設設定」の右の施設名(立川病院など)を、「施設設定」と同じ大きさ(1.15rem)に。色(グレー)・太さは従来のまま。PC・スマホ共通。
- 「施設設定」の右横に、各設定項目と同じ **ⓘ**(同じサイズ・色・間隔・動作。PCはホバー、スマホはタップ)を追加し、常時表示していた「この画面は施設管理者のみ変更できます。」を削除(同じ文をⓘのツールチップに移動)。権限のチェックは変更なし。
### ディーラーのメール欄
- 「発注用メールアドレス」「使用報告用メールアドレス」の補足説明を、どちらも **「（1行に1件・最大5件）」**に統一し、同じグレー・同じ大きさ・太さ(`.field-note`)に。以前の「（発注用とは別に管理）」は削除。
- **使用報告用の上限を確認**: 画面の検証(`parseEmailList` は発注用・使用報告用で共通、上限5件)と Firestore Rules(`validEmailList` も5件まで)とも、**使用報告用も最大5件**で、表記どおり。6件入力すると、使用報告用のエラーで保存されないことをテストで確認。メールアドレスの保存・送信処理は変更なし。
- 変更: `src/ui/facility-settings.js`、`styles.css`。
