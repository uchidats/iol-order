## 変更内容
- **スマホ幅(640px以下)**で、レンズの「IOLモデル」「IOLパワー」のネイティブ select メニュー(Androidでは画面幅いっぱいに広がる)の代わりに、カスタムドロップダウンを表示。**PC幅は従来のネイティブ select のまま**(見た目の統一感を維持)。
- メニュー: 幅 240〜280px、1項目 42px、白背景・濃いグレーの文字(**ダークモードでも固定**)、選択中は**青いチェックマーク**、メーカー別のグループ見出しを維持、多いときはメニュー内でスクロール(最大約8項目の高さ)、画面外にはみ出さないよう上下左右の位置を自動調整(下に収まらなければ上に開く。狭い画面でも左右8pxの余白内)。
- 元の select は値の保持用に残し(見えない・タップを受けない)、選ぶと select の値を変えて change を発火する。そのため、既存の選択処理(度数の作り直し・度数の維持・検証)や注文データは変わらない。コードやテストからの値の変更もボタンの表示に反映される。キーボード(Enter/↑↓/Esc)・外側タップで閉じる・Safariのフォーカスにも対応。
- 実装: `src/ui/custom-select.js`(新規)、`src/ui/lens-lines.js`(2つの select に適用)、`styles.css`。注文処理・送信・Firebase は変更なし。
