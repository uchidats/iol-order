  - 手術日順: 今週(日本時間の月曜〜日曜)から、既存の `week` を週ごとに読んで手術日の早い順に連続表示。週の区切り(「11月9日〜15日の週」)→ 手術日 → 医療機関名 → レンズ行。下の「もっと見る」で先の週、上の「過去の注文をもっと見る」で前の週を足す(上に足しても見ている行の位置を保つ)。1回に最大4週まで、予定のない週を飛ばして探し、見つからなければ案内(もう一度押すとさらに先)。予定のない週が続く所は1行にまとめる。`truncated`(1週100件の上限)の週は、区切りに「一部だけを表示しています」と明示。行を押すとその受注の詳細。週は重ならないので境目で重複・欠落しない。
