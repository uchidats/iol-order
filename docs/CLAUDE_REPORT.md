## 変更内容
- 保存済みのディーラーは、入力欄の枠なしで名前を通常のテキストとして表示。名前の下に登録状況(「発注用メール N件 ・ 使用報告用 N件」。発注用メールが0件なら「発注用メール未登録(自動送信不可)」)。
- 各行の右側に「編集・↑・↓・削除」の4ボタン(担当医と同じクラス・サイズ・配置。ブラウザテストでサイズ・スタイル・右端位置が担当医と一致することを確認)。
- 鉛筆を押した行だけ入力欄に切り替わる(名前・発注用メール・使用報告用メール。行の「保存」「キャンセル」)。編集中に「ディーラーを保存」を押すと、編集中の行を先に保存/キャンセルするよう案内(担当医と同じ)。
- 「ディーラーを追加」「ディーラーを保存」は担当医のボタンと同じデザイン。追加した行は編集状態で表示(キャンセルで消える)。
- 並び替えは既存の `sortOrder` に保存(10刻み)。発注先の判定(0社/1社/複数社の選択・サーバー検証)には使わない(選択肢の表示順だけ)。
- 既存の発注用メール・使用報告用メール(各最大5件、別管理)は維持。検証(名前の重複・メール形式)は既存の `validateDealers` / `planDealerWrites` をそのまま再利用。削除は確認ダイアログ付きで従来どおり。
- スマホ幅(390・320px)でボタンが重ならず、横にはみ出さないことをテストで確認。
- 変更範囲: `src/ui/facility-settings.js`(ディーラー部分)、`styles.css`(追加5行)、`index.html`(バージョン付与)、テスト。注文処理・Cloud Functions・Rules・データは変更なし。
