## 変更内容
- 「採用IOLを保存」「担当医を保存」ボタンを**廃止**。ディーラー・利用者管理など他のセクションは従来どおり(変更なし)。
### 採用IOL
- チェックの変更、メーカーの↑↓、メーカー内のIOLの↑↓のたびに自動保存(採用状態は `adoptedIols`、並び順は `displaySettings/iolOrder`。既存の保存処理をそのまま使用)。画面は作り直さない(操作中の開閉・スクロールを壊さない)。
### 担当医
- 追加・設定変更(名前・メール)・並び替え(↑↓)・削除で自動保存。**入力途中は保存せず**、行の「保存」(追加・変更の確定)を押した時点で保存。追加した担当医には、保存後すぐ ID が付き(読み直して対応付け)、続けて並び替えても重複して作られない。既存の担当医データ・表示順(`sortOrder`)は維持。削除は保存と直列に実行(削除した担当医を、保存が書き戻さない)。
### 共通
- 成功の通知は出さない。**失敗したときだけ**「保存できませんでした。変更はまだ保存されていません。…」と「再試行」ボタンを表示。画面の変更は消さず(再試行・次の操作で、画面の最新の状態をもう一度保存)、失敗したまま「注文画面に戻る」を押すと確認が出る。保存中に閉じるときは、保存の完了を待つ。
- **連続操作の競合対策**: 保存は同時に1つだけ(直列)。各保存は「その時点の画面の状態」を保存し、保存中に続けた操作は1回にまとめて保存するので、古い内容で最新の内容を上書きしない。
- 権限(Firestore Rules・管理者のみ)・既存の注文機能・Functions・Rules は変更なし。変更は `src/ui/facility-settings.js`、文言(見出しの説明)のみ。
