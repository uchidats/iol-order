## 変更内容
### 担当医
- スマホ幅の担当医の選択は、すでにIOLモデル・IOLパワーと同じ白背景のカスタムドロップダウン(前回の変更)。今回、**選択中の項目を「薄い青の背景 + 青いチェックマーク」**に統一(モデル・度数・担当医で共通。「選択」の未選択の行は青くしない。ホバー/キー選択中はやや濃い青)。選択ボックスとメニューの幅は揃えたまま、現在の幅(150px)を維持。
- PC幅のネイティブ select にも `color-scheme: light` を適用(下記)。
### 手術日カレンダー
- 日付入力(`input[type=date]`)と、レンズの選択(select)に **`color-scheme: light`** を適用。ダークモードの端末でも、カレンダー・選択メニューがライトモード(白背景・濃い文字)で表示されるようにする設定。デザイン・操作方法は変更しない(カスタムカレンダーへの置き換えはしていない)。**ページ全体のテーマは変更しない**(ルートの color-scheme は従来どおり)。
- **実機での確認について(重要)**: カレンダーは端末(Android Chrome)の標準部品で、画面の外側に表示されるため、この環境(PC上のブラウザの自動テスト)では**実際の見た目を確認できない**。テストでは、ダークモードを指定した状態で、日付入力・選択に `color-scheme: light` が適用され、ページ全体は変わらないことまでを確認した。Android Chrome の日付ピッカーは入力要素の `color-scheme` に従うのが標準の仕様だが、**実機のAndroid(ダークモード)で、手術日のカレンダーが白背景になるか、ご確認ください**。ブラウザ側の制約で白くならない場合は、お知らせください(カスタムカレンダーへの置き換えは、ご指示があるまで行いません)。
- 変更は `styles.css` のみ(数行)。入力機能・注文データ・Firebase は変更なし。
