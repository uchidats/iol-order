## 変更内容
- 「確認画面へ進む」を押すと、入力チェックのあと、**最新の注文履歴(施設全体・最新300件)を照会**して、今回のレンズと照合する。
- **判定**: IOLモデル(トーリックは正式型番まで)・度数・手術日・担当医がすべて一致したレンズ。枚数は含めない。レンズごとに判定し、同じレンズに一致する過去の注文が複数あれば、すべての注文日を表示。下書き・送信失敗(failed / notification_failed)・キャンセル・却下の注文と明細は対象外。旧形式の注文(注文全体の orderer)も照合する。
- **警告画面**: 見出し「過去の注文と一致するレンズが○件あります」。**重複したレンズだけ**を、1レンズ2行で表示(1行目: 青い「レンズN」バッジ[注文フォームと同じ見た目・元のレンズ番号] + IOLモデル + 度数。「／」は使わず余白で区切る / 2行目: 「過去の注文日：YYYY/MM/DD」。複数あれば「、」で並べる)。最後に「今回の注文に間違いありませんか？」と **「注文内容を修正」「確認して続行」** の2つのボタン(重複が複数でも確認は1回)。スマホでもコンパクト(390/360/320pxで確認)。
- **確認後**は通常の確認画面へ進み、最終の「注文を送信」の確認手順は省略しない(重複していても発注は許可)。修正した場合は、次に「確認画面へ進む」を押したときに再判定する。重複がなければ従来どおり確認画面へ。履歴を照会できなかった場合は、注文を止めず、通知を出して確認画面へ進む。
