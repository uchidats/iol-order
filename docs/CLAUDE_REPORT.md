## 変更内容
### 入力内容の自動保存・復元
- 入力が変わるたびに(入力は少し待ってから、モデル・絞り込み・レンズの追加/削除/元に戻す・画面を離れるときはすぐ)、localStorage に下書きを保存。モデル・度数・枚数・トーリック/多焦点・手術日・担当医・発注先・備考・追加したレンズをすべて保存し、リフレッシュ・ブラウザの再起動後に自動復元(「入力途中の内容を復元しました」の通知)。
- **ログインユーザー・施設ごとに別のキー**(`iol-order-draft:v1:{uid}:{施設ID}`)で保存し、他のユーザー・施設の下書きは読まない。保存するのは選んだ値(担当医・発注先は ID)だけ。認証情報(トークン等)・患者情報の項目は保存しない(余計な項目は捨てる)。備考は自由記述のため、備考欄に患者情報を書かないよう運用で注意が必要。ログインユーザーが分からない開発用の静的モードでは使わない。
- **注文が正常に完了したときだけ削除**。送信失敗(エラー・開発モードの dryrun)では残る。完了後に画面を離れても保存し直さない。空の状態では下書きを作らず、残っていれば消す。14日より古い・壊れた・版が違う下書きは捨てる。
- **復元後も入力チェックを維持**: モデルは今の選択肢にあるものだけ、度数はそのモデルの選択肢にあるものだけ、担当医・発注先はマスターに今も存在するものだけ復元(なければ未選択)。過去の手術日は復元しない。確認画面へ進むときの検証は従来どおり。
### レンズカードのゴミ箱
- 各レンズカードの右上に、控えめなゴミ箱アイコン(従来の「削除」ボタンを置き換え)。タップでそのレンズだけ削除。**確認ダイアログなし**、画面下に「レンズNを削除しました [元に戻す]」の通知。レンズ番号は自動で振り直す。「元に戻す」で元の位置・同じ内容に戻る。
- **最後の1枚は削除せず、空の入力カードに戻す**(元に戻せる)。削除・元に戻すの結果は、下書きにも即時反映。
