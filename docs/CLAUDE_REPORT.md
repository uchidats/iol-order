- AB-02: 端末の値を、発行したときの認証主体(Google・Microsoft の固有ID、メールリンク)に結び付け、閲覧では今回の主体と同じ主体に発行した値だけを認める(サーバーで確認)。旧主体に発行した値の置き換え後の利用、Google・Microsoft の値の password での利用、方式をまたいだ転用を拒否。置き換えた主体の紐付けと、その主体に発行した値も消す。

- AB-04: 保存領域(localStorage)の取得自体が拒否されても起動し、メモリの値で使えるようにした。
- AB-01・AB-05 の対応は維持。
