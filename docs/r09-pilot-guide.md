# IOLシール写真 試験運用の手順(立川病院)

試験運用の間だけ使う手順書です。正式なマニュアル(画面の「使い方・ヘルプ」)には、一般公開のときに載せます。
この機能は、試験運用の対象の施設だけに表示されます。ほかの施設の画面には出ません。

## 1. できること

- 手術室で、使用済み IOL のシールを貼った台紙をスマートフォンで撮影して送る(ログイン不要。QR とアクセスコードを使う)。
- 医療機関の利用者全員が、送られた写真を一覧と拡大表示で確認する。
- 施設が共有を許可したディーラーが、許可の後に送られた写真を確認する。

## 2. 守ること

- **患者氏名・患者 ID を台紙に書かない。写真に写さない。**
- アクセスコードを台紙・QR のそばに書かない。口頭や院内の決まった方法で伝える。
- 写真の保存・転送は、この画面の外では行わない(画面にダウンロードのボタンはありません)。

## 3. 最初の準備(施設管理者・副管理者)

メニュー「☰」→「施設設定」→「IOLシール写真」で行います。

注文者・代理入力者も、同じメニューから「IOLシール写真」の欄を開けます。できるのは、発行済みの QR コードの表示と、台紙・QR コードの印刷です(下の 2・3)。QR コードの最初の発行は、管理者・副管理者が行います(未発行のときは、依頼の案内が出ます)。アクセスコードの設定と変更、QR コードの作り直し、ディーラーへの共有も、管理者・副管理者だけが行えます。

1. **アクセスコードを設定する。** 「設定」を押し、半角数字 6〜12 桁を入力する。保存の直後に1回だけ表示されるので、その場で控える。後から表示し直すことはできません(忘れたら変更します)。
2. **QR コードを確認する。** 「QRコード」の右の「表示」で、施設専用の QR が出ます。
3. **台紙を印刷する。** 「表示」で開いた画面の「台紙を印刷」で、A4 の台紙(QR 付き)を印刷する。QR だけを印刷するときは、同じ画面の「QRコードのみ印刷」を使う。上部の「施設名 → 発注先」は印刷の画面で直せます(保存はされません)。手持ちの台紙に貼るときは「QRコードのみ印刷」を使う。
4. **(任意)ディーラーへ共有する。** 「ディーラーへの共有」で、写真を見せる発注先にチェックを入れる。チェックの後に送られた写真だけが、そのディーラーに見えます。チェックを外すと、すぐに見えなくなります。
   - 一覧に発注先が出ないときは、運営者による会社との関連付けがまだです。運営者へ連絡してください。
   - 注文の「ディーラー画面での閲覧」の許可とは別の設定です。片方を変えても、もう片方は変わりません。

## 4. 撮影して送る(手術室のスタッフ)

1. スマートフォンのカメラで、台紙の QR を読み取り、開いたページを表示する。
2. アクセスコードを入力する(毎回入力します。端末には保存されません)。
3. 施設名が正しいことを確かめ、台紙全体が写るように撮影する。
4. 写真を確認する。ぼけているときは「撮り直す」。
5. 必要なら「今回の最終手術日」を入れる(任意。最初の1枚のときだけ)。
6. 「送信」を押す。「送信しました」が出たら完了。続けて撮るときは「続けて撮影」、終わるときは「終了」。

- 送信に失敗したときは、そのまま「再送信」を押す(同じ写真が二重に保存されることはありません)。
- 30 分たつと、コードの再入力を求められます。写真は残っているので、コードを入れると自動で送り直します。
- ページを閉じると、撮影中の写真とコードは端末から消えます。

## 5. 写真を確認する

- **医療機関**: 注文画面の「関連リンク」を開き、「IOLシール写真」を押す。送信日ごと・撮影のまとまりごとに並びます。写真を押すと拡大します。
- **誤って送った写真の削除**: 施設管理者・副管理者が、拡大表示の「削除」から行う。**削除した写真は復元できません。**
- **ディーラー**: ディーラー画面のメニュー「☰」→「シール写真」(共有を許可された施設があるときだけ表示)。

## 6. 困ったとき

| 状況 | 対応 |
| --- | --- |
| 「コードが違います」 | コードを確かめる。分からないときは、管理者がコードを変更する(3-1) |
| 「しばらくしてからお試しください」が続く | 誤ったコードの入力が続いて、確認が止まっています。管理者が施設設定を開くと、停止中の案内が出ます。**アクセスコードを変更すると、すぐに再開できます。** 心当たりがないときは、あわせて「QRコードを作り直す」を行い、台紙を刷り直す |
| QR を外部に出してしまった・台紙をなくした | 管理者・副管理者が、施設設定の「QRコード」の見出しの ⓘ を開いて「QRコードを作り直す」を押す。古い QR は使えなくなるので、台紙を刷り直す |
| コードを知られたかもしれない | アクセスコードを変更する。送信中の端末は、コードの再入力が必要になります |
| カメラが起動しない | ブラウザのカメラの許可を確かめる。使えないときは、ページに出る「カメラで撮影」のボタンから撮影する |
| 関連リンクに「IOLシール写真」が出ない | ページを再読み込みする。出ないときは運営者へ連絡する |

## 7. 試験運用で確かめたいこと(気づいた点を運営者へ)

- 使った端末(機種・ブラウザ)と、読み取り・撮影・送信にかかった時間。
- 写真でシールの文字(型番・度数・シリアル)が読めるか。台紙の枠の大きさ・行数は足りるか。
- 院内の Wi-Fi と携帯の回線での送信の様子。
- 分かりにくい文言・操作。

## 8. 試験運用をやめるとき

運営者が機能を停止します。停止の間は、撮影・閲覧・設定のすべてが使えなくなり、メニューも表示されません。保存済みの写真は、運営者と相談のうえで扱いを決めます。
